# Project working agreements

Read `docs/PROJECT_SPEC.md`, `VERIFICATION.md` and the relevant package README first.
Keep the project overview and verification scope aligned with actual behavior.

This is a standalone sharing edition. Preserve existing user changes. Do not add
private service adapters, original project history, credentials, personal paths,
runtime data or raw logs. Follow `SECURITY.md` and `SHARING.md`.

Run the affected package's offline tests after behavior changes. Keep simulated
data labeled and isolated from real caches. Dependency checks do not establish
provider availability. Never infer data timestamps, units or adjustment conventions.

Use synthetic fixtures for reports and tests. Publication, visibility changes,
account access and external messages need applicable user authorization.
