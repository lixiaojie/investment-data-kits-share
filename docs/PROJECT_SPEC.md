# 当前项目概览

核对日期：2026-09-21。版本：MDK 0.5.2+share.1 / NDK 0.2.1+share.1。
阶段：独立试用版；长期维护与公开开源尚未承诺。

## 目的与范围

为个人研究工作台提供可安装的数据获取层。MDK 提供港/美/A 股日线、快照、指标与缓存；
NDK 独立提供 RSS、清洗、标签、去重和 SQLite 查询。扩展接口的在线能力依赖上游源与权限。
不提供交易、分钟线、托管行情 API、原项目运行数据或统一数据再分发授权。

## 架构与约束

`packages/` 包含两个可独立安装的 Python 包。公开源适配器按配置启用，
默认不连接 OpenD。MDK 返回来源、复权、时间、新鲜度与模拟标记，缓存按请求隔离。
NDK 使用包内 RSS 配置与显式名称词表，持久化去重并记录实际抓取状态。
接口差异与数据语义见两个包 README；代码与数据许可边界见 SHARING.md。
